# 版本记录

## 本地开发增量 — 空白取消选择与页面信息（2026-09-21）

- 点击画布留白、根布局间隙或外侧空白清除单选/多选，保留显式 AI 引用。
- 未选择时右侧展示页面名称、组件/布局数量、编辑提示和「页面布局」入口；组件选中后恢复属性编辑。

## 本地开发增量 — 多组件上下文（2026-09-21）

- ⌘ / Ctrl + 点击在画布与结构树中多选，显示数量与选中列表，一次加入单个 AI 上下文附件。
- 附件携带全部节点身份和已保存属性；普通换选不改引用，失败重试保留原组，删除部分保留剩余引用。
- 保留单节点附件字段与已有属性编辑、复制删除和增量渲染。多选为当前面板临时状态，不改变持久页面协议。

## 本地开发增量 — 选中操作与局部更新（2026-09-21）

- 选中时显示源组件库的复制/删除与移动按钮；上下文改为显式加入，引用内容继续同步。
- 画布按节点复用 Renderer，普通拖入/移动不清空重建；保留本地交互状态，防止晚到保存覆盖新选区。
- Foundation 和图标统一引用组件库；编辑器属性类隔离，避免与组件内部样式同名。

## 本地开发增量 — 拖拽落点预览（2026-09-21）

- 增加蓝色占位块、组件名/容器/位置提示，以及已有组件平滑让位；支持索引插入、移动排序、嵌套布局和横向换行/分栏。
- 长页面边缘滚动、取消还原、原位放回不写历史，失败/冲突保留已保存页面；拖动预览不写页面协议。
- 修正长画布被压缩、空布局快速松手漏放置、目标因重排跳位及浏览器默认滚动在取消后继续滑动的问题。
- 保留源组件的实现/样式和手动库更新机制；无新依赖，不更改已发布的 v0.1.1 标签。

## 本地开发增量 — 编辑协议 v1（2026-09-18）

- 新增独立 builder-contract.json 消费者、严格版本/字段/控件/枚举/条件检查，源元数据驱动分组、中文名称、选项、条件控件与结构化属性编辑。
- 支持源声明的简单伴随更新；旧库及未声明的复杂变体继续使用兼容适配器。布局与组件 props 保持分离。
- 元数据参与既有快照/手动重载，错误候选保留当前页面。组合属性草稿可应用或取消，阻止其他操作静默丢弃草稿。
- 五组件 76 字段、37 变体、四标签类型、数字空值、图片、嵌套编辑及原生元数据重载通过定向联调。真实 Codex 已打开面板的加载状态仍单独记录。
- 此项是本地开发构建，未修改已发布 GitHub v0.1.1 标签。

## 0.1.1 — 2026-09-18

按用户指定版本号归档此前开发增量；替代工作区使用的 0.2.0 开发编号，历史安装版本及验收记录保留原编号。

### 本版包含

- 编辑器控件复用真实 B2B 组件库；五个适配组件支持公开属性编辑、37 种变体与 4 种标签类型，选项中文显示、源 API 原值保存。
- 独立组件库按不可变快照绑定页面，提供「刷新并重载组件」，通过兼容校验后更新实现、样式及公开属性；保留页面内容、排列与历史，无后台自动更新。
- 修复原生资源加载及手动重载白屏；重载保留宿主连接，释放旧运行资源和事件监听，失败恢复与重试。
- 完善复杂变体转换、头像/媒体/页签编辑、写入前 Renderer 校验和跨进程版本冲突保护。
- 修复上下文空附件、重复发布及超时处理；记录共享页面、上下文与组件库更新的架构和回归证据。
- 发布包携带组件校验所需的 Playwright Core，独立安装无需开发目录的 node_modules。运行要求为 Node.js 20+ 和本机 Chrome（或 CHROME_PATH 指定的兼容浏览器）。

### 已知边界

- 当前适配 C-02、C-21、C-23、C-34、C-42。常用字段顺序、中文词典及复杂变体转换仍在插件中；完整编辑描述协议、页面容器设置与编辑器扩展协议尚未实现。
- 组件库兼容更新可通过按钮生效；插件自身代码更新的可靠加载方式仍为重新加载宿主，不具备已验证的插件热更新机制。
- 用户反馈的 Codex 上下文附件展开错误尚缺实际报错证据；空附件修复不能等同于该问题已解决。
- 原生资源沙箱与真实 Codex 面板验收分别记录。源码版本提交不代表已重新安装或由当前面板加载。

### 验证

已有定向验收涵盖完整源库变体、同 props 样式对照、独立刷新、原生连续重载/失败恢复、上下文桥接、保存重开及窄屏。详情见仓库 `docs/ACCEPTANCE.md`、`docs/PROGRESS.md` 和 `docs/COMPONENT_LIBRARY_LIFECYCLE.md`。

版本归档前重新执行 build、typecheck、18 项单元测试、1 项 MCP 集成测试、官方插件校验及版本一致性检查，全部通过。此轮只调整版本与归档文档，沿用已完成的浏览器定向验收，不重复全量浏览器测试。
