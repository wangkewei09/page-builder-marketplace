# 搭建器自身使用设计系统

日期：2026-09-16。需求 U10，来自用户对当前插件界面的直接反馈。首版改造已实现；本文件同时保留约束与实际选型证据。

## 已核实的问题

`src/ui/index.html` 与 `src/ui/app.js` 的工具栏、搜索、页签、属性编辑器等仍创建原生控件；`styles.css` 独立定义控件外观与大量颜色、字体、圆角。画布调用了真实组件 Renderer，但这不等于搭建器本身已经使用组件库。此前“真实组件已接入”的结论需明确其范围。

## 实现边界

采用设计系统模式，保留搭建器现有任务和区域：顶部页面操作、左侧组件/页面结构、中央画布、右侧属性。新功能遵循已确认需求；不为更换 UI 增加营销区、演示业务数据或第二套聊天框。

- 标准控件通过 `B2B.loadComponents()` / `B2B.renderComponent()` 创建。先读真实 `describe().api.props`、协议符合性、事件和键盘约定；等待 `ready` 并检查 `validate()`。不得复制 specimen、手写近似控件、仅贴类名或用页面 CSS 改造组件内部。
- 整体颜色、字体、外部间距、表面和边框使用当前设计系统公开 Token 与 Layout 规则；不保留另一套复制数值的视觉体系。允许有语义别名，但值应引用实际 Token。组件内部视觉由 Renderer 决定。
- 搭建器拥有区域 Grid/Flex、滚动、组件素材条目、结构树的数据关系、拖拽命中、选中框和插入位置。先确认库中有无相应组件，只有库未覆盖的编辑器专属行为才做最小页面组合，并记录理由。
- 只监听组件公开业务事件。不得为组件内部按钮、下拉项等重复绑定点击/键盘，也不得因整块重绘造成输入焦点、中文输入法组合状态或未提交内容丢失。
- 文件选择等浏览器能力可以作为不可见的底层功能，用户可见操作仍复用合适的组件。无法表达的必需能力记录规范缺口，不能静默换为另一套近似控件。

## 选型记录要求

以下只是按 manifest 与选择指南核实的候选方向，具体 props、变体及可组合能力必须由开发任务读取目标 `describe()` 后确定，并落在实现记录中。

| 界面用途 | 候选方向 | 必须核对的行为 |
|---|---|---|
| 预览、导出、加入对话、删除等命令 | C-02；低优先级动作按按钮家族选择 | disabled/loading、动作只触发一次、危险语义 |
| 撤销、重做、复制、移动等图标操作 | C-04 | 可访问名称、合法图标与尺寸、Tooltip、禁用状态 |
| 页面名称、组件搜索、文字属性 | C-21 | 受控值、输入/变更/清空事件、多行与搜索的合法变体、输入法 |
| 变体、尺寸及其他枚举属性 | C-23 | 值回填、选项、禁用、键盘、弹层可见范围 |
| 组件 / 页面结构切换 | C-41 | 完整 tablist/tabpanel、公开内容插槽、焦点与选中状态同步 |
| 布尔属性、视口选择 | 按任务判断 C-11/C-27 或 C-22 等 | 复选、开关与单选语义不同，不因外观相近混用 |
| 保存状态、失败、空态与短反馈 | 按内容判断 C-42/C-49/C-36/C-50 等 | 状态含义、持久/短时提示、可访问反馈 |
| 窄工作区的辅助面板 | 先评估 C-46 与公开组合能力 | 组件/属性入口始终可访问、关闭后焦点回到触发入口 |

按钮选型还需调用 `B2B.describeComponentFamily("button")`。每个实际使用项记录组件 ID、API、props、公开事件、Token/布局来源、是否由父 Renderer 内部拥有和例外原因。不能将候选表当作适配或验收完成的证明。

L-05 的三栏主次布局规则与现有拓扑相近，可作为核对入口；最终需说明布局来源和区域映射。窄工作区不能简单隐藏属性面板导致无法编辑，也不能压缩标准组件的内部尺寸来塞进屏幕。

## 与组件库独立更新的关系

遵循 [组件库独立更新](COMPONENT_LIBRARY_LIFECYCLE.md)：区分编辑器自身使用的已验证资源版本，以及当前页面绑定的不可变组件版本。更新编辑器控件资源不能静默升级旧页面。

必须证明两者的全局样式、Token、运行时、公开事件不会互相污染；实现选择写入架构。若使用不同文档隔离，仍要维持选区、拖拽、缩放、截图和 AI 操作闭环。不能为了隔离违反组件库关于 ShadowRoot/document 委托交互的约定。

## 验收与证据

不修改组件库本体时执行 Level P。若确需修改组件、Renderer、共享资源或协议，先按组件库 AGENTS 选择 Level C 范围并说明理由。

| 编号 | 完成条件 |
|---|---|
| E01 | 编辑器标准控件确实来自真实 Renderer；调用记录与浏览器实例相符，无手写同类控件/内部 CSS 覆盖 |
| E02 | 编辑器整体 Token/布局来源可追溯；工具栏、侧栏、属性、反馈状态的截图与计算样式得到检查 |
| E03 | 每个实例 ready/validate 成功；实际使用的组件/变体/关键状态完成适用的鼠标、键盘、焦点、ARIA 和事件次数检查 |
| E04 | 改名、搜索、切换面板、拖入、编辑文字/变体/avatar、复制删除、撤销重做、预览、导出保持可用；连续输入与重复切换无串扰 |
| E05 | 目标 Codex 工作区宽度下可访问组件和属性面板，弹层不被裁切，页面无意外横向溢出；实际视口与证据明确记录 |
| E06 | 编辑器与画布多实例/不同版本共存互不污染；独立更新后旧页面及既有导出保持绑定版本 |
| E07 | 构建、独立浏览器、已安装插件与原生右侧入口分别记录版本和结果；不能用源码截图替代用户实际入口验收 |

浏览器无法覆盖的宿主行为明确标为待验收；发现失败不得以只读源码、DOM 类名或测试数量代替真实结果。

## 实际选型与实现证据

| 用途 | 实际组件与公开事件 |
|---|---|
| 预览、导出、加入对话、删除 | C-02；`b2b:button-activate` |
| 撤销、重做、移动、复制、添加、属性面板入口 | C-04；`b2b:icon-activate` |
| 页面名称、搜索、文本/数字/多行属性 | C-21；`b2b:input-change` |
| 枚举属性 | C-23；`b2b:select-change` |
| 组件/结构、桌面/移动切换 | C-41；`b2b:tabs-change`，外部 panelContainer 使用完整 tabpanel 所有权 |
| 布尔属性 | C-11；`b2b:checkbox-change` |
| 保存和宿主连接状态 | C-42 |
| 短反馈和错误 | C-49 |

启动时实际调用 `B2B.describeComponentFamily("button")`；所有挂载统一调用 `renderComponent`、记录 audit.valid 并在替换前销毁实例。设计系统控件内部没有项目 CSS 覆盖。页面自有 CSS 仅处理三栏/窄屏面板、滚动、素材条目、树、拖拽命中和画布选中，颜色别名引用 `--b2b-*` Token。

浏览器回归验证 E01–E06：标准控件宿主均为 `data-ui-renderer-valid=true`，C-42 avatar 转换、输入、搜索、页签、添加、删除、撤销重做、预览交互通过，控制台 0 错误；800×800 下通过 C-04 入口打开右侧属性覆盖层。证据截图为 `/tmp/page-builder-development-qa.png`（临时验证文件，不纳入仓库）。E07 的 Codex 原生右侧入口仍需安装后的真实宿主操作。
