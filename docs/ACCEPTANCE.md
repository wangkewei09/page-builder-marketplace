## 必跑的一条完整使用流程

目标 Codex 安装并打开 → 新建页面 → 拖入分栏、输入框、两个按钮、选择器、标签、卡片 → 移动和改文字/变体 → 删除并撤销 → 选中后用 AI 修改 → 制造一次旧版本写入冲突并确认用户内容保留 → 保存重开 → 切换预览 → 导出到独立目录运行 → 导入页面描述继续编辑。

实际无法操作宿主时可先完成浏览器路径，但 A17 保持未通过，并记录缺少的宿主证据。截图只证明画面；拖拽、持久化和 AI 操作需要交互及数据证据。

## 评审与复测记录格式

在 PROGRESS 记录检查版本、评审方式（自审或真实独立评审）、检查范围、发现和剩余限制。问题包含：验收编号、触发条件、实际后果、文件位置、严重程度、复现证据、修复与复测结果。没有发现问题时也要说明查了什么，不能写无范围的“全部没问题”。

数据损坏、关键流程不可用、越权读取、无法重建运行的缺陷阻断首版完成。修复时保留原复现方式；关键逻辑缺陷形成回归用例。其余问题明确影响和处理状态。
